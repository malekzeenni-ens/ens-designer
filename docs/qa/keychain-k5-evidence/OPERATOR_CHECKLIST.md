# Keychain K5 — LightBurn and material checklist (operator)

Samples: `samples/` (generic names, generated by `scripts/keychain_validate_exports.py` from commit `57ae14f`). Software measurements for each file are in `samples/validation-report.json`.

Use your normal, proven 3 mm Cast Acrylic cut/engrave settings. These files don't prescribe power or speed. Record results in the table and return it, with screenshots, to update `KEYCHAIN_K5_VALIDATION_REPORT.md`.

## A. LightBurn import (save your current work first; use **File → New**)

For 01 (engraved), 04 (Layered combined) and 05 (Layered separate):

1. Import the SVG. Note any import warning.
2. Layers: backing black `#000000` (or `#1E3A8A` in 04) is a cut layer; text red `#FF0000` (or `#F59E0B` in 04) is engrave (01) or cut (04/05). Groups make sense.
3. Select only the product geometry (not the page). Width/height match within 0.1 mm: 01 = 60.0 × 34.6 mm; 02 = 40.0 mm wide; 03 = 90.0 mm wide; 06 = 30.0 mm high.
4. The ring hole is a real inner cut contour of 5.0 mm (4.0 mm in 02, 6.0 mm in 03). No fill, duplicate cuts or broken paths. Check with the node editor or Edit → Select open shapes (expect none).
5. For 05, import `-backing.svg` and `-text.svg` at the same origin: the text sits exactly inside the backing.
6. Any manual repair needed = **fail** (report it as a defect).
