## Contract changes and verification evidence

- D1: Layered `CUT_TEXT` is welded compound polylines at export tolerance. Engraved `ENGRAVE_TEXT` keeps original Q/C curves unless explicitly reinforced. Preview hit targets remain per glyph. Layered curve preservation is intentionally superseded; the validator's Q/C assertion now applies only to engraved text, and overlap is asserted on every cut layer. This is stricter manufacturing validation, not a skipped test.
- Unexpected engine failures intentionally changed from generic 400 to generic 500. The existing API test was renamed/updated accordingly. Download-contract assertions intentionally changed from immediate to delayed URL revocation.
- Baseline: **332 backend / 115 frontend** tests. Recovered final logs at current implementation HEAD: **374 backend / 134 frontend** tests; frontend TypeScript/Vite build passed. Backend emitted the existing Starlette/httpx deprecation warning. Logs: `logs/r1-baseline-{backend,frontend}.log`, `r1-backend-tests.log`, `r1-frontend-tests.log`, `r1-build.log`.
- `logs/r1-golden.log`: **3/3 byte-identical**. Fixtures and their hashes were never regenerated.
- Fresh `logs/r1-resume-export-validator.log`: **6/6 sample sets pass**, including zero cut-layer overlap within 1e-6 mm². Regeneration reproduced tracked sample bytes. PNG uses Pillow fallback because native Cairo is absent; Cairo parity remains unverified.
- E1 timing recorded in `2fb95a0` (22 Cake Topper cases, five iterations, outline + ring): SVG-stage p50 sum **674.6 → 36.0 ms**, worst case **89.0 → 5.3 ms**, median total **63.0 → 42.9 ms**. ## Open items and acceptance limits

### R1-PERF-01 — warm-preview performance gate (open)

The recovered 20-iteration, 22-case `keychain-r1-benchmark.json` **fails** the unchanged <=150 ms warm API p95 budget. Worst warm API p95 **285.784 ms**, cold API **307.602 ms** (budget <=800), export **494.415 ms** (budget <=1500). Slow warm cases: script Maximilian 285.784 ms, script Mr Bear 182.060 ms, serif Maximilian 164.936 ms. All 22 converge and have zero production-error checks. This result supersedes the earlier F1 commit's statement that its benchmark passed; that earlier statement does not establish final R1 performance acceptance.

A fresh sequential run is retained separately as `keychain-r1-resume-benchmark.json`: gate **FAIL**, worst warm API p95 **291.972 ms**, cold API **315.815 ms**, export **443.038 ms**, 22/22 converged, zero production errors. An intermediate run overlapping pytest was retained only in local ignored logs and is not the committed final remeasurement. Fresh targeted R1 tests passed **41/41** (`logs/r1-resume-regressions.log`). No budget, corpus, test or geometry tolerance was weakened. Timing includes geometry, checks, FastAPI validation/serialization and TestClient overhead, but no browser/network. Cause is not established; do not attribute it to host load without a controlled measurement. Profile slow cases and compare the same corpus on the same host before scheduling broader optimization. Performance acceptance remains open even though the requested correctness fixes are implemented.
