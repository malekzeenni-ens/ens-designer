# 1. Purpose

This document records the manual LightBurn import validation for Phase 1C.

It serves as the permanent evidence that SVG files generated by the Etch 'N' Shine AI SVG Generator import correctly into LightBurn with:

- Correct millimetre dimensions
- Valid path geometry
- Correct bridge placement (where applicable)
- No stray elements or geometry errors

---

# 2. LightBurn Import Procedure

For each validation case:

1. Start the application at `http://localhost:5173`.
2. Enter the specified text and select the specified font and material.
3. Click Generate.
4. Click Download SVG.
5. Open LightBurn.
6. File → Import → select the downloaded SVG.
7. Confirm the following:
   - Width and height match the application output in mm (within ±0.5mm).
   - All letter paths are visible.
   - Bridge rectangles (if present) appear as thin connecting elements between letters.
   - No stray paths or geometry errors are present.
   - LightBurn "Optimise" does not produce unexpected path changes.
8. Record the result in the Evidence Table below.

# 5. Pass Criteria

A validation case Passes when:

- LightBurn dimensions match application dimensions within ±0.5mm.
- All letter paths visible.
- No geometry errors reported by LightBurn.
- Bridges (where expected) are visible as thin connecting elements.

A validation case Fails when:

- Dimensions are significantly wrong (>1mm difference).
- Paths are missing or corrupted.
- LightBurn reports SVG import errors.

# 6. PNG Rendering Decision

## Current Status

PNG export uses CairoSVG where Cairo DLLs are available and falls back to Pillow on Windows without Cairo.

## Decision

**Position for Phase 1C:** Accept Pillow fallback as the short-term position.

PNG is a preview and sharing format only. SVG is the production source of truth. The Pillow fallback produces acceptable preview quality for Phase 1C.

Revisit for Phase 1C or Phase X if Cairo can be installed on the production machine without additional complexity.

## Action Required Before Phase 2

Before Phase 2 delivery, attempt to install Cairo for Windows (MSYS2 or GTK runtime) to enable CairoSVG high-fidelity PNG rendering.
