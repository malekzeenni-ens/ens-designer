# Keychain Designer K3 — Workspace handoff

Date: 2026-11-09 (Europe/London). K3 implementation complete; the user explicitly reserved the K5 testing pass for later and authorised continuing directly into K4.

## 1. Executive summary

Added a dedicated Keychain tab directly after Designer. It composes the K2 API with live preview, production settings and SVG/PNG export while preserving the existing Designer panels.

## 2. Objectives completed

Name/style/presets, shared visual font picker, supporting-font filter, finished size/units/material, backing, ring controls and drag, spacing/gaps/dots, layer colours, layer view/zoom, production checks and downloads. Empty names render a disabled-export placeholder. Existing tab state survives React Activity switching.

## 3. Scope delivered

Feature-local models, pure reducer, request conversion, preview hook, API/download helpers, controls and preview. Text edits debounce 150 ms, controls 120 ms and font hover 250 ms. Each request aborts its predecessor and checks the echoed sequence ID. Errors preserve the last good SVG and disable stale export. Export errors require explicit confirmation; separate Layered exports expose two named download buttons, with one server export/history write.

## 4. Files created

`frontend/src/features/keychain/`: state types/reducer, units, API helpers, preview hook, `Fields`, `FontSection`, `KeychainControls`, `KeychainPreview`, `ProductionCheckPanel`, `KeychainTab`, scoped CSS and tests.

## 5. Files modified

`App.tsx` registers the tab in an Activity boundary. Shared FontPicker/FontNamePreview gained optional name-sample and hover callbacks; their default behaviour remains unchanged. README, phase/index/QA and deployment documentation updated.

## 6. Technical decisions

Use the existing navy/gold theme tokens and display-only units. The white artwork canvas keeps black cut geometry visible in both appearance modes. Canvas mapping uses margin-inclusive dimensions and aspect-ratio letterboxing; readouts show finished product dimensions. Font suitability comes from the existing Adviser classification, with no invented badge for unknown fonts. Character support loads on demand with six concurrent workers and a per-font promise cache.

Changing a name or font invalidates shaped glyph/gap indices, so those name-specific edits reset while font-independent production settings remain. Font-hover previews clear incompatible indices without modifying the committed recipe. Ring ghost movement is a direct DOM transform and commits physical offsets on pointer release; cancellation drops the ghost.

## 7. Architecture changes

Isolated frontend feature module; no CakeTopperPanel, PreviewPanel, backend geometry or history schema changes. K4 extends the reducer and canvas contracts.
