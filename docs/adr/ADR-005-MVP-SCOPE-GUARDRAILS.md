# ADR-005-MVP-SCOPE-GUARDRAILS.md

## Status

Accepted

## Decision

Constrain MVP delivery to a local-first, single-user, one-design-at-a-time workflow delivered through Phase 1A, Phase 1B, and Phase 1C.

## Context

The project must remain realistic for a solo-founder business and should not absorb enterprise, marketplace, cloud, batch, or collaborative complexity before the core production workflow is proven.

## Approved MVP Guardrails

The MVP must remain:

- Local-first
- Single-user
- One design at a time
- SVG-first
- LightBurn-focused
- Focused on 3mm Cast Acrylic, 3mm Mirror Acrylic, and 3mm Plywood

## Explicitly Out Of Scope For MVP

- Cloud sync
- Marketplace functionality
- Multi-user collaboration
- Batch generation
- Team workflows
- Manufacturing simulation
- Advanced AI features
- DXF implementation

## Consequences

- Phase 1 remains achievable.
- Architecture decisions stay grounded in business value.
- Future expansion remains possible after the production workflow is proven.
