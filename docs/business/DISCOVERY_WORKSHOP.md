# Objective

This document exists to ensure that all business, technical, UX, laser-cutting, AI, and architectural requirements are understood before any development begins.

No specification documents should be produced until all discovery questions have been answered.

---

# Discovery Process

The Product Manager must act as:

- Product Manager
- UX Specialist
- Laser Cutting Expert
- Solution Architect
- AI Product Strategist

The objective is to identify:

- Missing requirements
- Hidden assumptions
- Business constraints
- Manufacturing constraints
- Technical risks
- Future scalability requirements

---

# Business Discovery

## Business Goals

1. What is the primary outcome expected from this application?

2. How many designs are currently created per week?

3. What is the average design preparation time today?

4. What percentage of designs are name-based products?

5. Is the application intended only for internal use initially?

6. Could the application become a commercial product later?

7. What are the most common personalised products currently sold?

8. Which products generate the highest revenue?

---

# User Workflow Discovery

## Current Process

1. Which software is currently used for SVG preparation?

2. Which steps consume the most time?

3. Which steps create the most errors?

4. How are fonts currently selected?

5. How are bridges currently added?

6. How is structural integrity currently validated?

7. How are completed files stored?

---

# Laser Cutting Discovery

## Machine Information

1. Which laser machines must be supported?

2. Which software must be supported?

3. Which materials are most common?

4. What material thicknesses are most common?

5. What minimum bridge width is considered acceptable?

6. What minimum stroke width is considered acceptable?

7. What causes the most production failures today?

---

# Font Discovery

## Font Library

1. Approximately how many fonts must be supported?

2. Will fonts be local only?

3. Are commercial fonts used?

4. Are script fonts the highest priority?

5. Are serif fonts required?

6. Are decorative fonts required?

7. Should users be allowed to upload fonts?

---

# SVG Generation Discovery

## Output Requirements

1. Must SVG remain editable?

2. Must layers be supported?

3. Must colours be preserved?

4. Must dimensions be embedded?

5. Must LightBurn settings be stored?

6. Should the SVG contain cut layers?

7. Should the SVG contain engraving layers?

---

# AI Discovery

## Future AI Capabilities

1. Which AI provider is preferred?

2. Is local AI desired?

3. Should image generation be optional?

4. Should vectorisation be automatic?

5. Should AI repair designs automatically?

6. Should AI suggest better layouts?

7. Should AI optimise structural integrity?

# Technical Discovery

## Architecture

1. Local desktop application or local web application?

2. Preferred frontend framework?

3. Preferred backend framework?

4. Windows only or cross-platform?

5. Offline operation required?

6. Should projects be saved locally?

7. Should version history exist?

# Exit Criteria

Discovery is complete only when:

- All questions answered
- Assumptions documented
- Risks documented
- Scope approved
- Future roadmap validated

Only then may specification documents be created.
