# DEVELOPMENT_CHECKLIST.md

## Purpose

This document provides a standard checklist that must be completed before any development phase is considered finished.

The checklist applies to:

- Claude Code
- Codex
- Future contributors

---

# Phase Readiness Checklist

Before starting development:

- [ ] Business requirements reviewed
- [ ] Product requirements reviewed
- [ ] Architecture reviewed
- [ ] Previous handoff reviewed
- [ ] Scope understood
- [ ] Risks identified
- [ ] Dependencies identified

---

# Development Checklist

During implementation:

- [ ] Feature implemented
- [ ] Error handling implemented
- [ ] Logging implemented
- [ ] Configuration externalised
- [ ] No hardcoded secrets
- [ ] Code follows project standards
- [ ] Architecture remains consistent

---

# Testing Checklist

Before completion:

- [ ] Unit tests created
- [ ] Unit tests passed
- [ ] Integration tests created
- [ ] Integration tests passed
- [ ] Manual testing completed
- [ ] Edge cases tested
- [ ] Regression testing completed

---

# SVG Validation Checklist

Verify:

- [ ] SVG generated successfully
- [ ] SVG opens correctly
- [ ] SVG imports into LightBurn
- [ ] Geometry remains connected
- [ ] No floating islands
- [ ] Scaling is correct
- [ ] Export is production ready

---

# Documentation Checklist

Update:

- [ ] README updated
- [ ] Architecture docs updated
- [ ] Phase docs updated
- [ ] Changelog updated
- [ ] Handoff updated
- [ ] Release notes updated

---

# Release Checklist

Before tagging:

- [ ] Scope complete
- [ ] Tests passed
- [ ] Documentation complete
- [ ] Handoff complete
- [ ] Risks documented
- [ ] Known issues documented

---

# Final Approval Checklist

- [ ] Acceptance criteria achieved
- [ ] Product objectives achieved
- [ ] No critical defects
- [ ] Release approved
