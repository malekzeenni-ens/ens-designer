# CHANGELOG_TEMPLATE.md

## Purpose

This document defines the changelog standard for the AI SVG Generator project.

Every release must include a changelog entry.

The changelog provides a historical record of:

- Features added
- Bugs fixed
- Architecture changes
- Breaking changes
- Known issues

---

# Changelog Format

Follow semantic versioning.

Example:

```text
v0.1.0
v0.2.0
v0.3.0
v1.0.0
```

---

# Release Entry Template

## [VERSION] - YYYY-MM-DD

### Added

- New features
- New modules
- New APIs

### Changed

- Behaviour updates
- Performance improvements
- UX improvements

### Fixed

- Bug fixes
- Validation fixes
- Export fixes

### Security

- Vulnerability fixes
- Dependency updates

### Documentation

- Updated documentation
- Updated handoff files

### Breaking Changes

- Describe any breaking changes

### Known Issues

- List unresolved issues

---

# Example

## [v0.1.0] - 2026-05-29

### Added

- Welded text generator
- SVG export
- PNG export
- Font selection
- Structural validation

### Fixed

- Initial geometry union issues

### Documentation

- Added architecture documents
- Added phase handoff

### Known Issues

- Some decorative fonts may require additional bridges

# Release Approval Checklist

Before adding a changelog entry verify:

- Tests passed
- Documentation updated
- Handoff updated
- Release approved
